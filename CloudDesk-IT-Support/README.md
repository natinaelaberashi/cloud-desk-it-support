# CloudDesk IT Support Ticket System

A clean, modern IT support dashboard designed for service desks, infrastructure teams, and internal help desk operations. This project demonstrates a realistic support workflow with ticket creation, priority tracking, filtering, and status monitoring.

## Project overview

This project is ideal for showcasing skills in:

- IT support operations
- Service desk ticketing
- Cloud and infrastructure troubleshooting
- Technical support workflows
- Front-end dashboard development

## Features

- Ticket creation form for new support requests
- Status tracking for Open, In Progress, Resolved, and Blocked tickets
- Priority labeling for Low, Medium, High, and Critical issues
- Search and filter logic by request, assignee, status, and priority
- Summary cards for operational visibility
- Responsive UI for desktop and tablet/mobile layouts

## Tech stack

- HTML5
- CSS3
- JavaScript (vanilla)

## Run locally

1. Open the project folder.
2. Start a simple local web server:

```bash
python -m http.server 8000
```

3. Open the browser at:

```text
http://localhost:8000
```
